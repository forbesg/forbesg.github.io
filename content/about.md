## In The Beginning

My name is Forbes Gray, a freelance website developer with over :years-experience years' experience building websites and web applications for a variety of businesses and industries, across Edinburgh and further afield.

My interest in web development started fairly late. I have a background in sales spanning 10 years in the telecoms industry. As my skills grew I started up my own company supplying telecoms to businesses.

As with any new start-up, spending money was not something I wanted to do too much of, and yet I knew the importance of having an online presence.

I decided to try and create my own website using the "user friendly" free tools that were available at the time. My emails were hosted by Google Apps, so I started off with Google Sites as a simple solution. Although it gave me a presence online, I was frustrated by the constraints of building with a tool like Google Sites (and I wanted rounded corners).

![My journey to web development](/images/journey.jpg)

I had never written any HTML or CSS at this stage, but felt that it couldn't be hard to create the simple site I was looking for. I started teaching myself HTML and CSS and very quickly was able to create a website that I was far more satisfied with but, more importantly, found that I really enjoyed doing it.

I continued to learn and optimise my company's site. To make the site more maintainable and interactive I started to learn a little PHP and got a firmer grasp of JavaScript.

I began some other web projects using the ever more popular content management systems such as Joomla, WordPress and MODX. With this came my introduction to databases and MySQL.

## Discovering NodeJS

With the growth of JavaScript and NodeJS, web applications were becoming ever more capable and I found my new challenge. JavaScript became my focus.

BlackBerry has always had a place in my heart, so I used their platform to hone my skills. Creating simple WebWorks/Cordova applications gave me small projects to discover the capabilities and pitfalls of JavaScript.

At the same time I was discovering more about running JavaScript on the server with NodeJS and interacting with NoSQL databases such as MongoDB and CouchDB. I created a couple of applications using the MEAN stack, with Angular on the front end.

As these new JavaScript frameworks developed I was introduced to a number of different approaches to a development project, but I always found myself striving for faster, more performant websites and applications.

## JAMStack Website Development

My main focus has become building fast, SEO friendly server-side rendered and static websites using modern JavaScript frameworks such as Vue, React, Gatsby, Gridsome and Nuxt (this website). Using a JAMStack architecture (JavaScript, APIs & Markup), headless databases, CMSs and ecommerce services, I am able to quickly create performant and secure websites and web applications that search engines love.

I have become increasingly focused on website speed, and since Google introduced [Core Web Vitals](https://web.dev/vitals/) as a metric in their organic search rankings, the JAMStack architecture has found its place at the forefront of modern web development.

As an early adopter of new web technologies I am always looking to embrace new tools and technologies that improve a website's performance and the user's experience.

Some of my website design and web application development work can be found on my [portfolio page](/portfolio/).
